# 🌐 Networking Labs – Progressive Network Configuration & Troubleshooting

## 📌 About the Project

**Networking Labs** is a practical networking project consisting of **20 progressive levels**, designed to develop and strengthen networking fundamentals through hands-on exercises and real-world network configuration scenarios.

The project starts with basic IPv4 addressing concepts and gradually advances to more complex subnetting, routing, and packet-tracing challenges.

Each level introduces new networking concepts and builds upon previously acquired knowledge, providing a practical learning experience that combines theoretical understanding with problem-solving skills.

## 🎯 Learning Objectives

The main goal of this project is to gain practical experience in:

- Understanding IPv4 addressing and network structures.
- Calculating subnet masks and network ranges.
- Applying IPv4 Subnetting and Supernetting techniques.
- Assigning IP addresses and subnet masks to network devices.
- Understanding network communication between hosts and routers.
- Configuring routing and default gateways.
- Tracking packets across network devices.
- Analyzing packet forwarding paths.
- Identifying routing conflicts, incorrect configurations, and network connectivity issues.
- Troubleshooting network communication problems.

## 📚 Topics Covered

| Topic | Description |
|---|---|
| IPv4 Addressing | Understanding IPv4 addresses and address structures. |
| Subnetting | Dividing networks into smaller subnets. |
| Supernetting | Combining multiple networks into larger address blocks. |
| Subnet Masks | Calculating and configuring subnet masks. |
| IP Configuration | Assigning IP addresses to hosts and network interfaces. |
| Default Gateway | Configuring gateways for communication between networks. |
| Routing | Understanding routing tables and packet forwarding. |
| Packet Tracing | Following packets through hosts, switches, and routers. |
| Network Troubleshooting | Identifying and resolving addressing and routing problems. |

## 📈 Project Structure

The project contains **20 levels** with gradually increasing difficulty.

- **Beginner Levels:** IPv4 fundamentals, IP addressing, and subnet masks.
- **Intermediate Levels:** Subnetting, network segmentation, and gateway configuration.
- **Advanced Levels:** Supernetting, routing tables, and communication between multiple networks.
- **Challenging Levels:** Packet tracing, routing analysis, conflict detection, and troubleshooting complex network topologies.

## 🧪 Practical Approach

Each level presents a network topology and a specific communication objective.

The task is to analyze the network, configure the required IP addresses and subnet masks, and ensure that packets reach their intended destinations.

The exercises focus on understanding:

- Forward and return packet paths.
- Routing table decisions.
- Network and broadcast addresses.
- Correct gateway selection.
- Packet forwarding between different subnets.
- Detecting routing loops and configuration errors.
